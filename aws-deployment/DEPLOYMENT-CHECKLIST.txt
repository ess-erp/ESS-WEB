🛑 COMMON ERRORS & SOLUTIONS
═══════════════════════════════════════════════════════════

ERROR: "Docker is not accessible"
SOLUTION: 
  - Wait 2 more minutes for Docker to fully start
  - Check system tray shows "Docker Desktop is running"
  - Close Command Prompt and open a NEW one

ERROR: "AWS CLI is not configured"
SOLUTION:
  - Run: aws configure
  - Enter your Access Key, Secret Key, Region (ap-southeast-1), Format (json)
  - Run deployment again

ERROR: "Cannot connect to Docker daemon"
SOLUTION:
  - Restart Docker Desktop
  - Wait for it to say "running"
  - Try again

ERROR: "Access Denied" during ECR push
SOLUTION:
  - Your AWS credentials don't have ECR permissions
  - Ask your AWS admin to grant you ECR push permissions
  - Or use an AWS account where you have admin access
