## Document Organization Rules

All newly created documentation files, guides, architectural refactoring documents, or markdown reports generated by Kiro MUST be placed inside this `/Documentation` folder.

- ✅ **Allowed:** `Documentation/*.md`
- ❌ **Prohibited:** Creating `.md` files directly in the root directory (except for system `README.md`)

## Contributing

When adding new documentation:
1. Place files in this `/Documentation` folder
2. Update this README with a link to the new document
3. Use clear, descriptive filenames (e.g., `FEATURE_NAME_IMPLEMENTATION_GUIDE.md`)
4. Include date and author information at the top of each document
